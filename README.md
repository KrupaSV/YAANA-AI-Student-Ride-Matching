# YAANA | AI-Based Student Ride Matching Platform

An intelligent student ride-sharing platform designed for Dayananda Sagar University (DSU) students.

## About the Project

YAANA aims to connect students travelling along similar routes, helping them find suitable travel partners and make commuting more convenient, affordable and efficient.

## Key Features

- Student registration and authentication
- Student profiles
- Create and manage trips
- Route-based ride matching
- Ride recommendations
- Interactive map and location features
- Driver registration and approval
- Admin dashboard

## Technology Stack

**Frontend:** React.js, JavaScript, HTML, CSS

**Backend:** Python, FastAPI

**Database and Authentication:** Supabase

**Machine Learning:** Python, Scikit-learn

**Development Tools:** Cursor, VS Code, Git, GitHub
